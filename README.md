## 4. Descrição do Problema Resolvido

O projeto tem como objetivo desenvolver um sistema para auxiliar no gerenciamento das informações de uma instituição de ensino.

O sistema permite organizar os dados de alunos, professores, cursos, matérias, atividades e notas, facilitando o cadastro, a consulta, a atualização e a exclusão dessas informações.

A proposta é centralizar os registros acadêmicos em um único sistema, tornando o gerenciamento das informações mais organizado.

## 5. Entidades Implementadas

O projeto contempla as seguintes entidades:

- **Aluno:** armazena as informações dos alunos cadastrados.
- **AlunoMatéria:** representa o vínculo entre alunos e matérias.
- **Professor:** armazena as informações dos professores.
- **Matéria:** representa as matérias oferecidas pela instituição.
- **Curso:** armazena as informações dos cursos.
- **Atividade:** registra as atividades acadêmicas, incluindo título, descrição, tipo, datas e relacionamentos com professor e matéria.
- **Nota:** armazena as notas dos alunos.

## 6. Instruções para Execução

1. Abrir o projeto na IDE utilizada para desenvolvimento.
2. Atualizar e configurar o JDK para a versão necessária (Java 25).
3. Executar o projeto por meio da opção **Run** da IDE.
